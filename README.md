
# Customer Retention & Churn Analysis

## Objective
Analyze customer behavior to identify churn patterns and retention drivers.

## Tools Used
- Excel
- Python
- Data Visualization

## Key Insights
- Customers with low usage are more likely to churn
- Basic plan has higher churn rate
- Short tenure customers leave more

## Recommendations
- Improve onboarding
- Offer loyalty benefits
- Reduce support response time
